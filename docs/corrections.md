# Activity deletion and manual street labels

`DELETE /api/activities/{id}` is owner-only and returns 204; missing and other-owner IDs both return 404. It cancels and lease-fences queued/running upload and coverage jobs, removes source rows and their per-dataset GPS support, deletes the activity, rebuilds each affected account/dataset summary, and queues private-file deletion in the same transaction. File cleanup is a durable `delete_private_object` worker job with an immutable object key captured from the source row; deletion is idempotent and retries on storage errors. Removing the source row releases exact-content deduplication so a later upload of the same bytes creates a new source and object key.

Deletion locks associated jobs by ID, then source rows, the activity, then account summaries by dataset ID, matching upload/matcher/requeue lock ordering. After source locks it re-reads associated job IDs without locking them. If a newly committed requeue changed the job set, the transaction rolls back and retries from the first lock; it never waits for a missed job while holding source locks. The retry is bounded at three attempts.

`PUT /api/streets/{id}/manual-completion?dataset_id=...` accepts `{ "reason": "..." }`; reason is trimmed and must contain 1–500 characters. `DELETE` on the same route undoes the label. Both require an active complete dataset and a street with eligible nodes. Writes are owner- and dataset-version-scoped, idempotent, and advance the account/dataset progress revision. Importing, retired, sampled, unknown, and zero-node streets are not writable. Manual labels mark no GPS nodes and never transfer to another dataset version.

Street `state`, `completed`, visited/missing nodes, and contributing activities remain GPS-only. Manual reads add `manual_completed`, `manual_reason`, and `effective_state` (or map `effective_completed`). A manual completion remains visible as effective completion while GPS matching is pending, while the GPS fields stay null. City/progress retain GPS `completed_streets` and add `manual_completed_streets` and `effective_completed_streets`; effective totals are null while GPS readiness is pending, and overlap between GPS and manual completion is counted once. Remaining-node lists continue to show actual GPS-missing nodes for manually labeled streets.
